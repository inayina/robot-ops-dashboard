# Screenshots

本目录用于保存作品集截图，例如 Dashboard 总览、任务下发、IMU 状态、Motor / Encoder bench 状态和异常断连画面。

推荐命名：

- `dashboard-overview-1440x900.png`
- `dashboard-task-dispatch-1440x900.png`
- `dashboard-recording-frame-1366x768.png`
- `dashboard-motor-curve-1440x900.png`
- `dashboard-evaluation-platform-1440x900.png`
- `dashboard-failure-cases-crop.png`

当前推荐用于 GitHub 与作品集的截图：

- `dashboard-overview-1440x900.png`：README 首图，展示 Dashboard cockpit 总览。
- `dashboard-task-dispatch-1440x900.png`：展示 AMR / WMS 任务下发与任务状态。
- `dashboard-motor-curve-1440x900.png`：展示 Motor / Encoder bench 曲线、STOP 口径和安全状态。
- `dashboard-evaluation-platform-1440x900.png`：展示 System Evaluation & Validation Layer。
- `dashboard-failure-cases-crop.png`：展示 failure cases 与质量检查；当前为页面内评估区块截图，便于避免顶部裁切。
- `dashboard-recording-frame-1366x768.png`：展示 60-90 秒录屏构图。

可用命令：

```bash
npm run capture:screenshots
```
